# 2.6 CSV Import Design

## Overview

The application provides CSV bulk-import capabilities for 5 entity types. Each import page offers a downloadable template and client-side validation before sending data to the server.

### Shared Infrastructure

| Feature | Source | Description |
|---|---|---|
| `parseCSV(text)` | each `.html` | Client-side CSV parser splitting on commas, respecting quoted fields |
| `normalizeCSVHeader(header)` | each `.html` | Strips trailing `\*` and whitespace from headers before matching |
| `csvEscape(value)` | each `.html` | Escapes commas, quotes, newlines in CSV output |
| `downloadCSVFile(filename, rows)` | each `.html` | Builds BOM-prefixed UTF-8 CSV and triggers download |

### Import Flow (all entity types)

```mermaid
flowchart TD
    A[User clicks ดาวน์โหลดแม่แบบ CSV] --> B[Template CSV downloaded with sample rows]
    C[User clicks เลือกไฟล์ CSV] --> D[FileReader reads UTF-8]
    D --> E[parseCSV → rows + headers]
    E --> F[normalizeCSVHeader strips * suffix]
    F --> G{Required headers present?}
    G -- No --> H[showToast error: หัวตาราง CSV ไม่ถูกต้อง]
    G -- Yes --> I[Build rows[] with field mapping]
    I --> J{rows.length > 0?}
    J -- No --> K[showToast: ไม่พบข้อมูลในไฟล์ CSV]
    J -- Yes --> L[google.script.run.serverImport...CSV TOKEN, rows]
    L --> M{Server response}
    M -- error --> N[showToast error]
    M -- success --> O[showToast success_count + warnings]
```

## 1. Users CSV Import

**File**: `src/admin_users.html` → `src/auth.gs:serverImportUsersCSV()`

### Template Headers

| # | Header | Required | Notes |
|---|--------|----------|-------|
| 1 | `user_id` | No | Leave blank for new users; auto-generated as `user_XXXX` |
| 2 | `username*` | **Yes** | Must be unique across Users table |
| 3 | `prefix` | No | Thai name prefix (นาย, นางสาว, ฯลฯ) |
| 4 | `first_name*` | **Yes** (if `full_name` absent) | Combined with `prefix` + `last_name` → `full_name` |
| 5 | `last_name*` | **Yes** (if `full_name` absent) | Surname |
| 6 | `full_name` | **Yes** (if `first_name`+`last_name` absent) | Full name overrides prefix+first+last composition |
| 7 | `role*` | **Yes** | `teacher` or `admin`; defaults to `teacher` |
| 8 | `initial_password` | **Yes** for new users | Required when creating; optional when updating existing |
| 9 | `must_change_pwd` | No | `true`/`1` → force password change on next login |

### Client-Side Validation

```javascript
// Required: username, role, AND (full_name OR first_name+last_name)
if (usernameIdx === -1 || roleIdx === -1 || 
    (fullIdx === -1 && (firstIdx === -1 || lastIdx === -1))) {
  showToast('หัวตาราง CSV ไม่ถูกต้อง...');
}
```

- Rows with empty `username` are skipped
- If `full_name` is empty, it's composed: `(prefix + first_name + " " + last_name).trim()`
- `role` defaults to `"teacher"` if missing

### Server-Side Validation (`auth.gs:240`)

| Check | Behavior |
|-------|----------|
| Blank `username` or `full_name` | Skip row, add warning |
| Invalid `role` | Default to `teacher`, add warning |
| Duplicate `user_id` | Update existing user |
| Duplicate `username` (no `user_id`) | Update existing user by username |
| New user without `initial_password` | Skip row, add warning |
| New user with `initial_password` | Hash with random UUID salt, store |
| Updated user with `initial_password` | Re-hash, update salt |
| `must_change_pwd` | Defaults to `true` for new teachers |

### Sample Template Rows

```csv
user_id,username*,prefix,first_name*,last_name*,full_name,role*,initial_password,must_change_pwd
,teacher01,นาย,สมชาย,ใจดี,,teacher,ChangeMe123,true
,admin02,นางสาว,สมหญิง,ดูแลระบบ,,admin,ChangeMe123,
```

## 2. Classes CSV Import

**File**: `src/admin_classes.html` → `src/admin_school_api.gs:serverImportClassesCSV()`

### Template Headers

| # | Header | Required | Notes |
|---|--------|----------|-------|
| 1 | `class_id` | No | Leave blank for new classes; auto-generated |
| 2 | `level*` | **Yes** | Grade level (e.g., `ป.1`, `ม.2`) |
| 3 | `section*` | **Yes** | Section/room number (e.g., `1`, `2`) |
| 4 | `homeroom_teacher_fullname` | No | Teacher's `full_name` from Users table; auto-mapped to `user_id` |

### Client-Side Validation

```javascript
// Required: level and section
if (levelIdx === -1 || sectionIdx === -1) {
  showToast('หัวตาราง CSV ไม่ถูกต้อง...');
}
```

- Rows with blank `level` and `section` are skipped
- `homeroom_teacher_fullname` matches against `full_name` in the Users table — the server resolves it to the correct `user_id`

### Server-Side Validation (`admin_school_api.gs:246`)

| Check | Behavior |
|-------|----------|
| Blank `level` or `section` | Skip row, add warning |
| `fullname` not found in Users | Warn and leave `homeroom_teacher_user_id` blank in DB |
| `fullname` matches multiple users (duplicate names) | Warn and leave blank — user must disambiguate |
| `fullname` matches exactly one user | Map to that user's `user_id` and store in `homeroom_teacher_user_id` column |
| Duplicate `class_id` | Update existing class |

### Sample Template Rows

```csv
class_id,level*,section*,homeroom_teacher_fullname
,ป.1,1,นายสมชาย ใจดี
,ป.2,1,
```

## 3. Subjects CSV Import

**File**: `src/admin_subjects.html` → `src/admin_school_api.gs:serverImportSubjectsCSV()`

### Template Headers

| # | Header | Type | Required | Notes |
|---|--------|------|----------|-------|
| 1 | `class_id` | ID | No | Leave blank to use `ระดับชั้น`+`ห้อง` lookup |
| 2 | `ระดับชั้น` | Thai | No* | Grade level (e.g., `ป.1`); required if `class_id` is blank |
| 3 | `ห้อง` | Thai | No* | Section number; required if `class_id` is blank |
| 4 | `รหัสระบบ` | ID | No | `subject_id`; leave blank for new subjects |
| 5 | `รหัสวิชา` | Code | No | Subject code (e.g., `ท11101`) |
| 6 | `ชื่อวิชา*` | Thai | **Yes** | Subject name (e.g., `ภาษาไทย`) |
| 7 | `จำนวนชั่วโมง` | Num | No | Hours per year; default per weight group |
| 8 | `กลุ่มน้ำหนัก` | Num | No | Weight group (1-3); defaults to `1` |
| 9 | `คำอธิบาย` | Thai | No | Subject description |
| 10 | `ก่อนกลางภาค` | Num | No | Pre-midterm max score (weight) |
| 11 | `กลางภาค` | Num | No | Midterm max score (weight) |
| 12 | `หลังกลางภาค` | Num | No | Post-midterm max score (weight) |
| 13 | `ปลายภาค` | Num | No | Final exam max score (weight) |

> *\* Either `class_id` OR both `ระดับชั้น`+`ห้อง` must be present to resolve the class.*

### Client-Side Validation

```javascript
// Required: subject name AND (class_id OR level+section)
if (nameIdx === -1 || ((classIdx === -1) && (levelIdx === -1 || sectionIdx === -1))) {
  showToast('โครงสร้างหัวตาราง CSV ไม่ถูกต้อง...');
}
```

- Blank rows (all key fields empty) are skipped
- `weight_group` defaults to `"1"` if blank
- Weight columns (`ก่อนกลางภาค`, `กลางภาค`, `หลังกลางภาค`, `ปลายภาค`) are optional — if provided, they create/update `SubjectWeights` entries

### Server-Side Logic

| Check | Behavior |
|-------|----------|
| No `class_id` but has `class_level`+`class_section` | Lookup class by level+section |
| No matching class found | Skip row, add warning |
| Duplicate `subject_id` | Update existing subject |
| Duplicate `subject_code`+`class_id` | Update existing subject by code+class |
| New subject | Auto-generate `subject_id` |
| Weight columns provided | Validate sum ≤ `coursework_max`; create/update `SubjectWeights` row |

### Sample Template Rows

```csv
class_id,ระดับชั้น,ห้อง,รหัสระบบ,รหัสวิชา,ชื่อวิชา*,จำนวนชั่วโมง,กลุ่มน้ำหนัก,คำอธิบาย,ก่อนกลางภาค,กลางภาค,หลังกลางภาค,ปลายภาค
,ป.1,1,,ท11101,ภาษาไทย,200,1,รายวิชาพื้นฐาน,30,20,20,30
,ป.1,2,,ท11101,ภาษาไทย,200,1,รายวิชาพื้นฐาน,30,20,20,30
```

## 4. Students CSV Import

**File**: `src/class_students.html` → `src/students.gs:serverImportStudentsCSV()`

### Template Headers

| # | Header | Required | Notes |
|---|--------|----------|-------|
| 1 | `student_id` | No | Leave blank for new students; auto-generated |
| 2 | `seq_no` | **Yes** | Seat/roll number in class |
| 3 | `student_code` | No | Student code (เลขประจำตัว) |
| 4 | `citizen_id` | No | National ID (เลขประจำตัวประชาชน) |
| 5 | `prefix` | No | Thai name prefix |
| 6 | `first_name*` | **Yes** (if `full_name`/`ชื่อ-สกุล` absent) | First name |
| 7 | `last_name*` | **Yes** (if `full_name`/`ชื่อ-สกุล` absent) | Surname |
| 8 | `full_name` | **Yes** (if `first_name`+`last_name` absent) | Alternative: full name. Thai alias: `ชื่อ-สกุล` |
| 9 | `dob` | No | Date of birth. Thai alias: `วันเกิด`. Accepted format: `01 ม.ค. 60` |
| 10 | `note` | No | Notes. Thai alias: `หมายเหตุ` |

### Client-Side Validation

```javascript
// Required: seq_no AND (full_name OR first_name+last_name)
if (seqIdx === -1 || ((firstNameIdx === -1 || lastNameIdx === -1) && nameIdx === -1)) {
  showToast('หัวตาราง CSV ไม่ถูกต้อง...');
}
```

- `findCSVHeaderIndex()` supports Thai aliases:
  - `seq_no` ← also `เลขที่`
  - `student_code` ← also `เลขประจำตัว`
  - `citizen_id` ← also `เลขประจำตัวประชาชน`
  - `full_name` ← also `ชื่อ-สกุล`
  - `dob` ← also `วันเกิด`
  - `note` ← also `หมายเหตุ`
- If `full_name` is blank, it's composed: `(prefix + first_name + " " + last_name).trim()`
- Rows with no `name`, `code`, and `seq_no` are skipped

### Server-Side Validation (`students.gs:160`)

| Check | Behavior |
|-------|----------|
| Missing `seq_no` | Skip row |
| Missing `full_name` | Skip row |
| Duplicate `student_id` | Update existing student |
| Duplicate `student_code` in same class | Update by code |
| New student | Auto-generate `student_id` |

### Sample Template Rows

```csv
student_id,seq_no,student_code,citizen_id,prefix,first_name*,last_name*,full_name,dob,note
,1,65001,,เด็กชาย,ตัวอย่าง,นักเรียน,,01 ม.ค. 60,
,2,65002,,เด็กหญิง,ตัวอย่าง,เรียนดี,,02 ม.ค. 60,
```

## 5. Indicators CSV Import

**File**: `src/admin_indicators.html` → `src/indicators.gs:serverImportIndicatorsCSV()`

### Template Headers

| # | Header | Required | Notes |
|---|--------|----------|-------|
| 1 | `indicator_id` | No | Leave blank for new indicators; auto-generated |
| 2 | `subject_id` | **Yes** | Pre-filled with current subject; rows with different `subject_id` are skipped |
| 3 | `code*` | **Yes** | Indicator code (e.g., `ต 1.1 ป.1/1`) |
| 4 | `description` | No | Indicator description text |
| 5 | `max_score` | **Yes** | Maximum score for this indicator |
| 6 | `display_order` | **Yes** | Sort order within the subject |

### Client-Side Validation

```javascript
// Required: subject_id, code, max_score, display_order
if (subjectIdx === -1 || codeIdx === -1 || maxIdx === -1 || orderIdx === -1) {
  showToast('หัวตาราง CSV ไม่ถูกต้อง...');
}
```

- `SUBJECT_ID` is required context (must have a subject selected before import)
- Template pre-fills `subject_id` column with current `SUBJECT_ID`
- Rows with different `subject_id` (if provided) are silently skipped
- Rows with empty `code` are skipped

### Server-Side Validation

| Check | Behavior |
|-------|----------|
| Blank `code` | Skip row |
| Auth not admin | Throw error |
| Duplicate `indicator_id` | Update existing indicator |
| Duplicate `code` within subject | Update existing by code |

### Sample Template Rows

```csv
indicator_id,subject_id,code*,description,max_score,display_order
,SUBJ001,ต 1.1 ป.1/1,ปฏิบัติตามคำสั่งง่ายๆ ที่ฟัง,3,1
,SUBJ001,ต 1.1 ป.1/2,ระบุตัวอักษรและเสียง,3,2
```

> *`SUBJ001` is replaced by the actual `SUBJECT_ID` in the template download.*

## Concurrency & Error Handling

All 5 server-side import functions share these patterns:

1. **Auth gate**: `if (!session \|\| session.role !== 'admin') throw new Error('ไม่มีสิทธิ์')`
2. **Lock**: `LockService.getDocumentLock().tryLock(30000)` — 30s timeout to prevent concurrent writes
3. **Batch processing**: Iterate all rows, collect success/warning counts
4. **Upsert logic**: Existing records (matched by ID or unique key) are updated; new records are inserted
5. **Return object**: `{ success_count, created_count, updated_count, warnings: [] }`
6. **Audit logging**: Each create/update appends to `AuditLog` sheet with `imported: true`

### Error Message Pattern

All imports return error messages in Thai:
- `หัวตาราง CSV ไม่ถูกต้อง กรุณาใช้แม่แบบ CSV` — Invalid CSV headers
- `ไม่พบข้อมูลที่จะนำเข้าในไฟล์ CSV` — No data rows found
- `เกิดข้อผิดพลาดในการประมวลผล: <message>` — Server processing error
- `อ่านไฟล์ CSV ไม่สำเร็จ: <message>` — CSV parse/read error
